# LinguaBot

Веб-приложение для изучения иностранных языков через разговорную практику, адаптивные упражнения и персональную обратную связь от ИИ.

LinguaBot разрабатывается как командный учебный проект. Его цель: помочь пользователю регулярно практиковать язык в ситуациях из повседневной жизни и понимать, как улучшить свои ответы.

## Текущий статус

Подготовлен архитектурный скелет: каталоги backend, frontend, инфраструктуры, документации и тестов. Пустые конечные каталоги содержат файлы `.gitkeep`, чтобы структура сохранялась в Git.

Код приложения, зависимости, конфигурация окружения, миграции и автоматические проверки ещё не добавлены. На этом этапе приложение нельзя запустить, а перечисленные ниже функции остаются планом разработки. Инструкция по запуску и проверке приложения появится вместе с соответствующей реализацией.

Проект ориентирован на веб-браузеры, включая мобильные устройства. Отдельные приложения для iOS и Android сейчас не предусмотрены.

## Планируемые возможности

| Направление | Возможности |
| --- | --- |
| Учётная запись | Регистрация, вход и профиль пользователя |
| Настройка обучения | Русский, английский и третий язык, который команда выберет позже; начальный, средний и продвинутый уровни; персональный план |
| Ежедневные мини-уроки | 5–10 слов или фраз в контексте, грамматическое объяснение и упражнение |
| Разговорная практика | Не менее 10 сценариев, включая знакомство, кафе, покупки, путешествия и деловые встречи |
| Упражнения | Адаптивные задания по грамматике, лексике и аудированию |
| Обратная связь | Объяснение ошибок, предложения естественных формулировок и тренировка произношения |
| Прогресс | История обучения, регулярность практики, выученные слова, освоенные темы и пройденные сценарии |
| Поддержка регулярной практики | Персональные рекомендации, достижения, ежедневные задания и напоминания |
| Внешние сервисы | Интеграции с ИИ-провайдером, словарями, переводчиками и речевыми сервисами |
| Офлайн-режим | Базовые упражнения без постоянного подключения к интернету |

## Технологический стек

Стек backend согласован для будущей реализации. Перечисленные компоненты пока не настроены в репозитории.

| Область | Выбранные технологии |
| --- | --- |
| Язык backend | Python 3.12 |
| HTTP API | FastAPI 0.110+ |
| Работа с данными | SQLAlchemy 2.0: асинхронный доступ и аннотации `Mapped[]` |
| Основная база данных | PostgreSQL 16 |
| Кэш и брокер фоновых задач | Redis 7 |
| Миграции | Alembic |
| Фоновые задачи | Celery 5 |
| Валидация данных | Pydantic v2 |
| Аутентификация | JWT |
| Backend-тесты | pytest, pytest-asyncio, httpx |
| Проверка качества кода | ruff, mypy |
| Логирование | structlog |
| Контейнеризация | Docker, Docker Compose |

Frontend-стек пока не выбран. Текущая структура frontend не закрепляет фреймворк, язык, сборщик, библиотеку состояния или способ передачи сообщений.

## Архитектура

Используется модульный монолит: один backend с функциональными модулями и отдельный frontend. Общие каталоги предназначены для инфраструктуры, документации и сквозных проверок.

Будущие маршруты, модели, схемы, бизнес-логика и доступ к данным каждой функции должны размещаться внутри её модуля в `backend/src/linguabot/modules/`. Общие каталоги `models/`, `schemas/`, `services/` и `repositories/` вне модулей не предусмотрены.

| Каталог | Ответственность |
| --- | --- |
| `backend/src/linguabot/api/v1/` | Подключение маршрутов модулей и организация версии API |
| `backend/src/linguabot/core/` | Общие настройки, безопасность и логирование |
| `backend/src/linguabot/db/` | Инфраструктура SQLAlchemy и подключения к PostgreSQL |
| `backend/src/linguabot/cache/` | Работа с Redis как кэшем |
| `backend/src/linguabot/modules/` | Функциональные модули приложения |
| `backend/src/linguabot/integrations/` | Адаптеры внешних ИИ-, словарных, переводческих и речевых сервисов |
| `backend/src/linguabot/ai/prompts/` | Шаблоны запросов к ИИ |
| `backend/src/linguabot/modules/dialogues/scenarios/` | Сценарии разговорной практики |
| `backend/src/linguabot/tasks/` | Инфраструктура и фоновые задачи Celery |
| `backend/migrations/versions/` | Миграции Alembic |
| `backend/tests/` | Модульные и интеграционные проверки, оценка качества ИИ-ответов |
| `frontend/` | Интерфейс, взаимодействие с API, локализация и офлайн-функции |
| `infrastructure/docker/` | Файлы контейнеризации |
| `tests/e2e/` | Сквозные проверки сайта |
| `.github/workflows/` | Автоматические проверки GitHub |

Учебная бизнес-логика должна оставаться в функциональных модулях. Интеграции отвечают за подключение к внешним сервисам, а каталог промптов хранит шаблоны запросов. Отдельный сервис `ai_agent/` и дополнительные микросервисы сейчас не предусмотрены.

## Получение проекта

Текущая общая ветка разработки: `develop`. На странице командного репозитория откройте **Code** и скопируйте адрес из вкладки **SSH** или **HTTPS**.

В команде ниже замените `URL_РЕПОЗИТОРИЯ` скопированным адресом. Выполните команды в каталоге, где хотите разместить проект:

```powershell
git clone --branch develop "URL_РЕПОЗИТОРИЯ" LinguaBot
cd LinguaBot
```

SSH-ключ должен быть настроен на вашем компьютере, а его публичная часть добавлена в ваш аккаунт GitHub. Каждый участник использует свой ключ. Инструкция: [подключение к GitHub по SSH](https://docs.github.com/en/authentication/connecting-to-github-with-ssh).

Клонирование получает структуру и историю проекта.

## Запуск

Реализованы регистрация и вход: backend на FastAPI с SQLAlchemy и JWT-токенами, база данных по умолчанию — SQLite (`backend/linguabot.db`). Формы входа и регистрации находятся в `frontend/login.html` и `frontend/register.html`.

Backend:

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn linguabot.main:app --reload
```

Сервер отвечает на `http://127.0.0.1:8000`, интерактивная документация API — на `http://127.0.0.1:8000/docs`. Настройки читаются из файла `backend/.env`; образец значений — `backend/.env.example`. Для перехода на PostgreSQL укажите `DATABASE_URL` вида `postgresql+asyncpg://...`.

Проверки backend:

```powershell
cd backend
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest
```

Frontend: запустите backend и откройте `http://127.0.0.1:8000/` — сервер сам раздаёт сайт (главная, формы входа и регистрации, стили и скрипты). Ссылки «Войти» и «Регистрация» в шапке ведут на формы, которые обращаются к тому же API.

## Работа в команде

Сейчас изменения проекта собираются в ветке `develop`. Порядок создания веток для отдельных задач и правила проверки изменений команда согласует перед началом совместной реализации.

Чтобы обновить уже клонированный проект, сначала сохраните текущие изменения в коммите, затем выполните:

```powershell
git switch develop
git pull --ff-only origin develop
```

При добавлении реализации:

- Размещайте связанные части функции внутри соответствующего модуля backend.
- Обновляйте README, когда появляются рабочие команды установки, запуска или проверки приложения.
- Сохраняйте необходимые `.gitkeep`, пока каталог не содержит других файлов, отслеживаемых Git.
- Храните локальные настройки и секреты вне коммитов. Шаблоны `.env.example` должны содержать только примеры без реальных токенов и паролей.

## Целевые критерии качества

Эти критерии относятся к будущему приложению и требуют проверки после реализации:

- Работа в Chrome, Firefox, Safari и Edge, включая мобильные браузеры.
- Безопасная аутентификация и защита пользовательских данных.
- Время ответа бота не более 3 секунд.
- Возможность начать первый диалог и получить обратную связь за 2 минуты.
- Не менее 70% тестовых пользователей отмечают улучшение разговорных навыков и снижение тревожности.
- Не менее 60% тестовых пользователей возвращаются ежедневно в течение тестового периода.

Наличие архитектурного скелета само по себе не подтверждает выполнение этих критериев.
