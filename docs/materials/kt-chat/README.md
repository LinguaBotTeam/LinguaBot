# Материалы проверки перехода «результат теста → чат»

Задача: ревью PR #7 `feat(frontend): переход из результата теста в чат`.

## Файлы

- `saved-chat.png` — скриншот диалога «В кафе» после перезагрузки страницы.
- `assessment-to-chat.e2e.spec.js` — черновик Playwright-сценария: тест уровня → «Перейти к чату» → новый диалог «В кафе» → сообщение с ошибкой → исправление → reload → сохранённая переписка.

## Как воспроизвести

1. Запустить backend из каталога `backend` по инструкции из основного README, задав `PYTHONPATH=src` перед командами Alembic.
2. Для сценария отправки сообщения нужен локальный провайдер Ollama либо тестовый HTTP-ответчик, совместимый с `POST /api/chat`.
3. Запустить сценарий из каталога с `playwright.config.js`, где `baseURL` равен `http://127.0.0.1:8000`.

## Результат проверки

- Переход по ссылке «Перейти к чату» открывает `chat.html` с авторизованной сессией.
- Создание диалога «В кафе» и отправка сообщения работают.
- В ответе сохраняются реплика пользователя, исправление и ответ ассистента.
- После reload история диалога загружается из API.
- Сценарий прошёл локально с тестовым Ollama-совместимым ответчиком: 1 passed.
