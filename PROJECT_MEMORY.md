# LinguaBot project memory

## Goal and acceptance criteria

Учебный веб-проект изучения языков. Выполненный этап: бэкенд личного текстового чата — создание диалога, сохранение сообщения пользователя и фиксированного ответа, загрузка истории, доступ только владельцу.

## Decisions and constraints

- Модуль чата расположен в `backend/src/linguabot/modules/dialogues/`.
- Используются существующие JWT `CurrentUser`, SQLAlchemy `Base` и `SessionDep`.
- Из существующего кода добавлены только подключение маршрутов в `api/v1/router.py` и импорт моделей в `db/session.py`; логика других модулей не менялась.
- Фронтенд чата и ИИ не реализованы. Проверять API можно через `/docs`.
- В чате нет `language_id`: справочник languages ещё не реализован.
- Сообщение и ответ записываются одной транзакцией; чтение/запись проверяют владельца.
- Диалоги сортируются по ID убыванию, история — возрастанию; limit 1–100, по умолчанию 100, offset от 0.
- Диалоговые ID ограничены 1–2147483647 для совместимости с PostgreSQL Integer.
