# Личные диалоги с ИИ

Модуль сохраняет личные диалоги и помогает практиковать английский. Ответ формирует выбранный провайдер через интерфейс `LanguageModel`: локальная Ollama или Cloudflare Workers AI. Модель предлагает исправленный английский текст, а сервер описывает на русском точные замены, добавления и удаления в `correction` сообщения пользователя. Если исправления нет, поле равно `null`. Это описание изменений, а не подробное объяснение грамматического правила; правильность предложенной английской фразы зависит от модели.

Сценарии: `introductions` — «Знакомство», `cafe` — «Кафе», `shop` — «Магазин». `free_chat` и неизвестные сохранённые сценарии используют общий разговорный промпт. Неизвестное название не передаётся как инструкция модели. Последний результат assessment задаёт CEFR; без результата используется A1. Логика assessment и авторизации не меняется.

## Запуск и проверка

Из `backend`, после настройки приложения:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m uvicorn linguabot.main:app --app-dir src --workers 1
```

По умолчанию задан `LLM_PROVIDER=ollama`. Нужен запущенный локальный Ollama с моделью `qwen3:4b-instruct-2507-q4_K_M` и отключёнными облачными функциями (`OLLAMA_NO_CLOUD=1` в окружении процесса Ollama). Для скачивания весов: `ollama pull qwen3:4b-instruct-2507-q4_K_M`. API не скачивает модель. Прежние настройки `LLM_BASE_URL`, `LLM_MODEL` и ограничения `LLM_*` относятся к Ollama.

Для Cloudflare сначала проверь, что выбранный аккаунт использует **Workers Free**. Затем заполни пустые `CLOUDFLARE_ACCOUNT_ID` и `CLOUDFLARE_API_TOKEN` из `backend/.env.example` в личном `.env` и задай `LLM_PROVIDER=cloudflare`. Токен требует Workers AI Read и Edit; Account ID состоит из 32 шестнадцатеричных символов. Разрешена только модель `@cf/meta/llama-3.3-70b-instruct-fp8-fast`. По умолчанию облачный тайм-аут равен 60 секундам, предел генерации равен 512 токенам. Все настройки и их ограничения приведены в [документации API](../../../../../docs/api/dialogues-ai.md).

Код не проверяет тариф Cloudflare. На Workers Free доступна общая квота аккаунта 10 000 нейронов в сутки со сбросом в 00:00 UTC; после её исчерпания запросы отклоняются. На Workers Paid расход сверх бесплатной квоты оплачивается, поэтому произвольный токен нельзя считать бесплатным. Эта конфигурация не предусматривает Workers Paid, AI Gateway, кредиты или платный fallback. Учётные данные новой интеграции пока не настроены; реальных вызовов Cloudflare и проверки тарифа не проводилось. [Правила квоты и оплаты](https://developers.cloudflare.com/workers-ai/platform/pricing/).

На CPU ответ Ollama может занимать значительное время. У Cloudflare скорость и количество доступных ходов зависят от мощности сервиса и общей квоты. Проверка небольшого набора примеров и автономные тесты с подставным ответом модели не гарантируют правильность исправлений.

Открой `http://127.0.0.1:8000/docs`. Зарегистрируй отдельного тестового пользователя, выполни login, затем вставь `access_token` в **Authorize** без префикса `Bearer`. Создай диалог:

```json
{"title": "Практика в кафе", "scenario": "cafe"}
```

Отправь `{"content": "I would like a tea, please."}` в `POST /api/v1/dialogues/{dialogue_id}/messages`. Ответ 201 содержит `user_message` и `assistant_message`; обе записи уже сохранены. `GET` того же пути возвращает историю. Если выбранный провайдер недоступен, ожидается 503 с текстом «Модель ИИ временно недоступна». Ошибка авторизации Cloudflare, квота, тайм-аут или неверные настройки также дают 503; некорректный ответ модели даёт 502. История остаётся прежней; запасного фиксированного ответа нет.

## Гарантии и ограничения

- Владелец проверяется до чтения контекста, результата теста и создания клиента модели. Чужой и отсутствующий диалог возвращают одинаковый 404.
- Модель получает доверенные инструкции, нормализованный уровень, текст текущего сообщения и ограниченную историю этого диалога. Поля аккаунта/профиля и результаты теста целиком не включаются. Сам пользовательский текст может содержать введённые пользователем сведения.
- При выборе Cloudflare контекст и текущая реплика передаются внешнему обработчику по HTTPS. Исключение полей профиля не удаляет личные сведения, которые пользователь написал в сообщениях.
- Контекст включает до 12 последних сообщений и до 4000 байт UTF-8 их текста. Старые сообщения удаляются из контекста целиком; оставшиеся идут по времени. Текущий текст передаётся целиком в пределах 4000 символов. Полная история доступна через прежнюю пагинацию.
- До завершения генерации записи и изменение `updated_at` не выполняются. После проверки ответа обе записи и время диалога фиксируются одним commit. Ошибка модели или записи откатывает весь ход.
- Одновременный ход в тот же диалог получает 409; его нужно повторить после ответа первого хода. Защита действует в одном процессе: запускай **один worker**. Для нескольких процессов потребуется координация через БД или отдельный сервис.
- Модель не получает инструменты или доступ к файлам. Промпт отделяет инструкции от недоверенных реплик; качество исправлений и устойчивость модели проверяются отдельно.
- Провайдер выбирается явно. Нет автоматических повторов, редиректов, системных HTTP-прокси и переключения на другую модель или провайдера при ошибке.

## Устройство

`repository.py` выполняет запросы без commit. `service.py` проверяет доступ, читает assessment, готовит контекст, вызывает модель и атомарно сохраняет пару. Доверенные темы находятся в `scenarios/`, общий промпт в `ai/prompts/dialogue.py`, адаптеры Ollama и Cloudflare в `integrations/llm/`. Оба адаптера проверяют один внутренний JSON-контракт `reply`/`corrected_text` и вызывают `build_correction` из `ai/feedback.py` для русского описания изменений без свободных грамматических утверждений модели. Публичный `ModelReply(reply, correction)`, схемы API и таблицы сохранены. Фабрика `get_language_model` выбирает адаптер по `LLM_PROVIDER`.

В ранее завершённой серии из 30 синтетических запросов к локальной модели все решения об исправлении совпали с ожидаемыми. Ручная проверка выявила повтор уже заданного вопроса, неестественную реплику об оплате и уход от вопроса о неизвестном личном факте. Эти результаты относятся к Ollama и не являются проверкой Cloudflare. Это демонстрационный вариант интеграции; полное качество преподавания и диалога не принято. Подробности и пределы проверки приведены в [документации API](../../../../../docs/api/dialogues-ai.md).

При использовании облачной модели: **Built with Llama**. Действуют [Llama 3.3 Community License](https://github.com/meta-llama/llama-models/blob/main/models/llama3_3/LICENSE) и [Acceptable Use Policy](https://github.com/meta-llama/llama-models/blob/main/models/llama3_3/USE_POLICY.md).

## Автономные тесты

Из `backend` в PowerShell, с отдельной SQLite:

```powershell
$previousDatabaseUrl = $env:DATABASE_URL
try {
    $env:DATABASE_URL = 'sqlite+aiosqlite:///./.venv/chat-ai-tests.db'
    .\.venv\Scripts\python.exe -m pytest -o pythonpath=src -q
} finally {
    $env:DATABASE_URL = $previousDatabaseUrl
}
```

Тесты заменяют внешнюю границу модели: API, авторизация, assessment и хранение работают реально. Проверяются прежний контракт, изоляция владельцев, пагинация, коррекции, уровень, ограничение истории, откат сбоев, перекрывающиеся ходы, выбор провайдера и обработка подставных ответов Cloudflare. Ollama, модель и учётные данные Cloudflare для них не нужны. Эти тесты не проверяют настоящий облачный сервис, его тариф или качество генерации.
